### 이프로젝트는 AI 개인 맞춤 영어학습 텔레그램 봇 입니다

개인용 영어학습 텔레그램 봇입니다. AI가 정답을 바로 알려주지 않고, 힌트 → 유도 질문 → 채점/피드백 순서로 스스로 생각하게 만드는 방식으로 학습합니다.
*클로드코드랑 같이 제작한 봇입니다*

✨ 주요 기능
1. 🤖 AI가 답을 먼저 안 줌 

- 해석·문법 전 영역에서 힌트 → 유도 질문 → 채점/피드백 순서로 진행하며, 정답을 바로 알려주지 않습니다.

2. 📊 오답 패턴 축적 

- 어떤 유형을 자주 틀리는지 데이터로 계속 쌓여서 학습이 갈수록 개인화됩니다.

3. 🔄 간격 반복(SRS) 기반 

- 단어 암기 클래스카드/Anki 방식으로, 정답률에 따라 복습 주기를 자동으로 조절합니다.

4. 📄 텍스트 붙여넣기 학습

- 소설/글/학교 수행평가 텍스트를 넣으면 모르는 단어 추출 → 암기 → 해석 → AI 피드백까지 자동으로 진행됩니다.

5. 🏫 학교 시험 관리 

- 시험/단원/자료를 묶어서 관리하고, 시험일까지 남은 기간(D-Day)에 맞춰 학습량을 자동 조절합니다.

6.📱 텔레그램 학습

 - 텔레그램 네이티브 별도 앱이나 웹사이트 없이, 텔레그램 안에서 모든 학습이 끝납니다.

기술 스택
Backend: Python + FastAPI
Database: PostgreSQL (Supabase)
Hosting: Render
AI: Gemini 2.5 Flash (기본), Claude API (필요시 보완)
Bot: Telegram Bot API (webhook)
